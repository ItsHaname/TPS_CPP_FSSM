# Exercice 2 : Recherche et Suppression d'un Élément dans un Tableau

## Objectif

Écrire un programme en C qui permet à l'utilisateur de saisir 10 entiers à stocker dans un tableau. Ensuite, le programme doit :

1. Demander à l'utilisateur de saisir un entier `V`.
2. Rechercher si l'entier `V` existe dans le tableau.
3. Si l'entier `V` est trouvé, supprimer la première occurrence en décalant les éléments suivants d'une case vers la gauche et en insérant un `0` à la fin du tableau.
4. Afficher le tableau final après cette suppression.
