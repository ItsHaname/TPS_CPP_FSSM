# Exercice 1 : Gestion d'une liste d'entiers

## Description
Ce programme permet de gérer une liste d'entiers avec un menu interactif. Vous pouvez ajouter des entiers à la fin de la liste, afficher la liste, supprimer le dernier entier ou afficher le dernier entier ajouté.

## Menu Interactif

========================================================
**Menu Principal**
========================================================
1. **Taper 1** pour ajouter un entier dans la liste  
2. **Taper 2** pour afficher la liste des entiers  
3. **Taper 3** pour supprimer le dernier entier de la liste  
4. **Taper 4** pour afficher le dernier entier saisi dans la liste  
5. **Taper 5** pour Quitter  
========================================================
